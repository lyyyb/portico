# Portico · 使用手册

面向「把 Portico 打包发给别人使用」的场景。功能特性、目录约定与配置字段见 [README](../README.md)。

## 一、交付包结构

压缩包里只需要这些内容：

```
Portico/
├─ portico.exe      # 主程序（约 10 MB）
├─ icon.ico         # 托盘图标，必须与 exe 同目录
├─ apps/            # 项目目录，首次启动自动创建
│  ├─ README.txt
│  └─ 订单系统/
│     ├─ index.html
│     └─ assets/
├─ apps.json        # 显示名、说明、排序、链接（自动生成）
└─ app.log          # 运行日志（自动生成，排错时看）
```

- `apps/`、`apps.json`、`app.log` 固定生成在 **exe 所在目录**，与从哪里启动无关。
- 不要把程序放在 `C:\Program Files` 这类需要管理员权限的位置，否则无法写入 `apps/`。
- `ui/launcher.html` 已编译进 exe，无需单独复制。

## 二、打包步骤

### 1. 编译

在源码根目录执行：

```powershell
go build -trimpath -ldflags "-s -w -H windowsgui" -o portico.exe ./cmd/portico
```

- `-H windowsgui`：不弹黑色控制台窗口，作为桌面程序运行。
- `-s -w`：去掉调试信息，减小体积。
- 需要固定版本号时追加：`-X portico/internal/version.Version=1.0.0`。

### 2. 准备目录

新建一个空文件夹，放入：

1. 编译出的 `portico.exe`
2. 仓库根目录的 `icon.ico`
3. 各项目目录：`apps/<项目名>/`，静态项目确保 `index.html` 在第一层

### 3. 交付前自检

双击 `portico.exe`，确认：

- 浏览器自动打开启动器页面，托盘出现图标；
- 静态项目能点开，程序型项目能启动、显示 PID、能停止；
- 关闭页面后再次双击 exe，不会启动第二份，只唤起已打开的页面；
- `app.log` 中没有报错。

确认无误后再压缩，避免把测试产生的 `app.log`、`apps.json` 一起发出去。

### 4. 压缩与交付

把整个文件夹压缩成 zip。不要直接放在共享盘上给多人同时使用，建议每人一份。

## 三、构建变体

```powershell
# 指定架构（默认跟随当前机器）
$env:GOOS="windows"; $env:GOARCH="amd64"; go build -trimpath -ldflags "-s -w -H windowsgui" -o portico.exe ./cmd/portico
$env:GOARCH="386"   # 32 位机器
```

> 如需支持 Windows 7，必须使用 Go 1.20 工具链编译（Go 1.21 起官方不再支持 Win7/8）。

## 四、对方电脑上的使用

1. 解压到任意可写目录，双击 `portico.exe`。
2. 浏览器自动打开启动器页面，点击卡片在新标签页进入项目，启动器页面保留。
3. 关闭浏览器标签页不会退出程序；左键单击托盘图标可重新打开页面。
4. 释放某个项目的端口：点卡片右侧的停止按钮，或右键托盘 →「停止全部应用」。
5. 完全退出：右键托盘图标 →「退出」。

> 关闭页面后端口仍被占用是设计如此：端口由 `portico.exe` 持有，浏览器无法可靠地通知服务端。点停止按钮即可释放。

需要开机自动启动时：按 `Win + R` 输入 `shell:startup`，把 `portico.exe` 的快捷方式放进打开的文件夹。

## 五、升级与卸载

**升级程序**

1. 右键托盘 →「退出」，确保进程已结束；
2. 用新的 `portico.exe` 覆盖旧文件；
3. 保留 `apps/`、`apps.json`、`icon.ico` 不动，配置和项目不会丢失。

**从旧版 `app-server.exe` 迁移**

程序已更名为 Portico，数据格式未变。退出旧程序后，把新 `portico.exe` 放到同一目录、删除旧的 `app-server.exe` 即可，`apps/` 与 `apps.json` 直接继续使用。

**卸载**

托盘退出后删除整个文件夹。程序不写注册表、不写系统目录。

## 六、交付排错

**双击没反应？**
先看同目录的 `app.log`。常见原因是程序已在运行（会直接唤起页面），或 `18080` 被其他程序占用，日志里会写明。

**页面打不开或一直转圈？**
可能被安全软件拦截了本地端口监听。把 exe 加入信任列表后重启程序。

**托盘没有图标？**
确认 `icon.ico` 与 exe 同目录；托盘被折叠时点击任务栏的 `^` 展开。

**怎么确认对方用的是哪一版？**
页面底部与托盘右键「关于」中都会显示版本号。
